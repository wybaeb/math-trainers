# Математические тренажёры

Интерактивные материалы для занятий: **проценты**, **округление**, **умножение столбиком и деление уголком**.
Сделано тач-первым — рассчитано на iPad (всё двигается пальцем), работает и мышью.

Открыть: https://wybaeb.github.io/math-trainers/

## Устройство

Статический сайт без сборки: чистые HTML/CSS/JS, на GitHub Pages кладётся как есть.

```
index.html            хаб с тремя темами
assets/app.css        дизайн-система (тач-размеры, светлая и тёмная тема)
assets/ui.js          общие помощники: DOM, прогресс в localStorage, проверка ответов, drag
assets/pie.js         секторная диаграмма (SVG, перетаскивание + прилипание)
assets/numberline.js  числовая полоска с засечками
assets/longmath.js    движок пошаговых разборов: умножение через частичные произведения
                      (`multiplyBySum`), классическое с переносом (`multiply`), деление уголком
assets/speech.js      чтение шагов вслух (Web Speech API), кнопка-переключатель
percent/              раздел «Проценты»
rounding/             раздел «Округление»
columnar/             раздел «Столбик и уголок»
```

Прогресс учеников хранится только в браузере (`localStorage`), ничего наружу не уходит.

## Разработка

Локально достаточно любого статического сервера:

```sh
python3 -m http.server 8080
```

Сквозная проверка (все задания решаются, счётчики сходятся, страницы переживают
испорченный localStorage, диаграмма работает без захвата указателя — как в Safari):

```sh
python3 -m http.server 8099 &
python3 tools/smoke.py
```

заданию — в [MAP.md](MAP.md).
